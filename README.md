# Distance and angle calculator

This is a static website. Open `index.html` in a browser to use it locally; it needs no Python server, packages, or build step.

## Publish with GitHub Pages

1. Push this repository, including `index.html`, to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing `index.html` (usually `main`) and the **/(root)** folder, then save.
5. When the deployment finishes, open the site URL shown in the Pages settings.

The calculator runs entirely in the visitor's browser. Results are shown on the current page without submitting coordinates to a server or navigating to another URL.
